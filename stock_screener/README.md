# 日本株 短期スクリーナー

東証プライムの大型株を中心に、テクニカル指標のルールで「短期的に条件の良い銘柄」を上位から抽出するツールです。
各銘柄について、**根拠・買い/売りの目安・同じルールを過去に当てはめた成績**を表示します。

> 株価の短期予測を「完璧に」行う方法は存在しません。本ツールは予測ではなく、事前に決めたルールに当てはまる銘柄を機械的に選び、そのルールの過去成績を示すものです。過去成績は将来の利益を保証しません。

## 使い方

```bash
cd stock_screener
pip install -r requirements.txt

streamlit run app.py        # 画面で使う（http://localhost:8501）
python cli.py               # ターミナルに上位5銘柄を表示
python cli.py --demo        # 架空データで動作確認（ネット接続不要）
python -m pytest -q tests   # テスト
```

- 株価は yfinance（Yahoo Finance の非公式ライブラリ）で取得します。日足ベースのため、**取引終了後（15:30以降）に実行し、翌営業日の判断に使う**想定です。
- 対象銘柄は `universe.py` で編集できます。画面のサイドバーからも銘柄コードを追加できます。

## 選定ルール

### スコア（100点満点）

| 区分 | 配点 | 加点条件 |
|---|---|---|
| トレンド | 25 | 終値 > 75日線（10）、25日線 > 75日線（10）、25日線が上向き（5） |
| モメンタム | 25 | MACD > シグナル（10）、MACDヒストグラム3日連続拡大（5）、直近5日以内のゴールデンクロス（10） |
| RSI(14) | 15 | 45〜65（15）、40〜45 または 65〜70（8） |
| 25日線乖離 | 15 | 0〜+5%（15）、+5〜+10%（5） |
| 出来高 | 10 | 5日平均/25日平均 1.3倍以上（10）、1.0倍以上（5） |
| 値幅 | 10 | ATR(14)が株価の1〜4%（10） |

### 買いシグナル（点灯条件・すべて満たす）

終値 > 25日線 > 75日線、25日線が上向き、MACD > シグナルかつヒストグラム拡大、RSI 45〜70、25日線乖離 0〜+8%、出来高比 1.0倍以上。

### 並び順と除外

1. 買いシグナル点灯 → スコア → 過去の平均損益 の順に並べる。
2. 25日平均売買代金が設定値（初期値10億円）未満の銘柄は除外。
3. 過去に3回以上取引があり、平均損益がマイナスの銘柄は除外。

### 売買の目安

| 項目 | 計算 |
|---|---|
| 買い | シグナル点灯の翌営業日の寄付き付近（押し目買いの目安 = 5日線 と 終値−0.5×ATR の高い方。ただし終値を上限とする） |
| 損切り | 買値 − 2×ATR |
| 利益確定 | 買値 + 3×ATR |
| その他の手仕舞い | 終値が25日線を下回る、または10営業日経過 |

倍率・日数・コストは画面のサイドバーで変更できます。

### バックテスト（過去成績）

約2年分の日足に同じ買いシグナルを適用し、翌日始値で買い、上記ルールで決済した結果を集計します。

- 同じ日に損切りと利確の両方に届いた場合は、**損切りを優先**（成績を甘く見積もらないため）。
- 窓を開けて損切り/利確ラインを越えた場合は、その日の始値で決済。
- 往復コスト（手数料・スリッページ）として初期値 0.2% を差し引き。
- 取引回数が少ない（10回未満）結果は信頼性が低い点に注意。

## 限界・注意

- 決算発表、ニュース、地合い（日経平均・為替）などは考慮していません。決算日をまたぐ保有は値動きが大きくなります。
- yfinance のデータには遅延・欠損・誤りが含まれることがあり、仕様変更で取得できなくなることもあります。
- バックテストは対象期間・銘柄選びの影響を受けます（現在の大型株だけを対象にしているため、過去成績が良く見えやすい「生存者バイアス」があります）。
- 本ツールは情報提供・学習目的であり、投資助言ではありません。他人に有償で売買推奨を行う場合は、金融商品取引法に基づく投資助言・代理業の登録が必要です。
